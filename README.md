# Appointment Scheduler System

This is a Python-based Appointment Scheduler System that helps manage patient appointments and detects time conflicts.

## Technologies Used
- Python

## Features
- Add patient appointments
- Enter start and end times
- Detect appointment time conflicts
- Prevent overlapping appointments
- Menu-driven interface

## Concepts Used
- Lists
- Loops
- Conditional Statements
- User Input
- Conflict Detection Logic

## Project Type
Python Console Application
